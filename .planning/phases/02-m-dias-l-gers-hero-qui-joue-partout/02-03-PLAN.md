**Presets sharp** (RESEARCH §sharp presets, déterministes, effort 4) :
- base : `sharp(file, { failOn: "none" }).rotate().resize({ width: t, height: t, fit: "inside", withoutEnlargement: true, kernel: "lanczos3" }).toColourspace("srgb")`, puis `.removeAlpha()` si l'image est opaque ; `sharp.cache(false)` ;
- photo :
  - avif `{ quality: 55, effort: 4, chromaSubsampling: "4:2:0" }` ;
  - webp `{ quality: 78, effort: 5, smartSubsample: true }` ;
  - repli jpg `{ quality: 80, mozjpeg: true }` si l'image est opaque, sinon PNG ;
- graphic :
  - avif `{ quality: 70, effort: 4, chromaSubsampling: "4:4:4" }` ;
  - pas de webp ;
  - repli png `{ palette: true, quality: 90, effort: 10, compressionLevel: 9 }`.

**Échelle** (Pitfall 9) :
- `longEdge` = grand côté après orientation EXIF ;
- `cap` = 2400, ou la valeur de `max` du manifeste (1200 pour les vignettes) ;
- cibles = [640, 1200, 2400] filtrées sur `< min(longEdge, cap)`, plus `min(longEdge, cap)` en rung de tête ;
- nom de fichier : `<nom>-<cible>.avif` / `.webp` ;
- descripteur `w` = `info.width` renvoyé par `toFile()`, jamais la constante ;
- repli unique à `min(640, longEdge)` : `<nom>.jpg` ou `<nom>.png` ;
- `width` et `height` de l'entrée = `info` du rung de tête.

**Faits à respecter** (RESEARCH §Images) :
- format réel lu par `metadata().format` : `Lyna.jpg`, `Joseph.jpg`, `Imad.jpg` et `portrait.jpg` sont des PNG avec alpha ;
- transparence = `(await sharp(f).stats()).isOpaque === false` ;
- 30 captures Display P3 sont converties en sRGB par `toColourspace("srgb")` ;
- ne jamais appeler `withMetadata` ni `keepIccProfile`.

**SSIM image** :
- référence = même base au rung 1200 (ou au rung de tête s'il est plus petit), écrite en PNG sans perte dans `media-src/.tmp/` ;
- l'AVIF de ce rung est décodé par sharp en PNG ;
- `ffmpeg -v error -i ref.png -i dec.png -lavfi "[0:v]format=rgb24[a];[1:v]format=rgb24[b];[a][b]ssim" -f null -`, puis lecture de `All:` ;
- seuils de WARN : graphic < 0,96, photo < 0,93.
