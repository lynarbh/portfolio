# Phase 2 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope of this contract (keep it tight):** (1) behaviour of the hero `<video>` plus a new play/pause toggle; (2) one `<Picture>` component that replaces every content `<img>`; (3) the Tafsut brand-guide gallery on « Identité d'un festival » plus the existing galleries pointed at `public/media/**`. **Nothing else visual changes in this phase.** The cinema frame, corner metadata, opening credits, logo grid, portrait animation and process strip belong to phases 3 and 4 and must not be started here.
>
> Sources: 02-CONTEXT.md (16 locked decisions), ROADMAP Phase 2, REQUIREMENTS (SIZE-01..06, SIZE-08, HERO-01, PROJ-06, PROJ-07), PITFALLS 1, 5, 6, 12, 13, `src/styles.css`, `src/routes/index.tsx`, `src/routes/projects/$projectId.tsx`, orchestrator pre-answers.

## Color

Values are the tokens in `src/styles.css`. Hex values are sRGB approximations for reference only. **Always reference the variable** (`var(--cream)` and so on), never the hex.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--cream` oklch(0.975 0.012 70) ≈ #FBF6EF, plus the hero video as page backdrop | Page background on project pages (`bg-[var(--cream)]`). On the home page the fixed hero video is the backdrop behind Hero, About and Contact. |
| Secondary (30%) | `--card` oklch(0.99 0.005 70), `--plum` oklch(48% 0.048 155 / 0.618) scrims, the hero gradient `rgba(61,31,58,0.55→0.85)` | `ornament-card` panels, the `quest-card` hover overlay, the hero darkening gradient, **the background of the new hero toggle** |
| Accent (10%) | `--gold` oklch(0.78 0.1 80) ≈ #E3B870 | See the reserved list below |
| Highlight (existing) | `--sakura` oklch(0.82 0.09 8) ≈ #F2B3BA | Focus ring (`--ring`), hover text colour, `<em>` in titles. Unchanged. |
| Destructive | `--destructive` oklch(0.6 0.2 20) | Not used. This phase has no destructive action. |

Accent (`--gold`) is reserved for:
1. `quest-btn` 1px border and corner brackets (existing)
2. `❀` / `·` ornaments between links and titles (existing)
3. `ornament-card` border at 35% (existing)
4. **The new hero toggle's 1px border**, `color-mix(in oklab, var(--gold) 70%, transparent)`, which mirrors `quest-btn`

Gold is **not** used for focus rings, icon fills, gallery frames or captions.

Contrast contract for the toggle (WCAG 2.2 AA):
- Icon: `var(--cream)` on a scrim of `color-mix(in oklab, var(--plum) 70%, transparent)` plus `backdrop-filter: blur(6px)`. The toggle sits in the bottom-right corner. On the hero, the bottom band of the existing gradient is ≥ 0.8 alpha of #3D1F3A, so even on a pure-white frame the backdrop resolves to about #5A4057 and cream reaches about 8:1. That clears both the 4.5:1 target and the 3:1 non-text minimum (1.4.11).
- The toggle is `position: fixed`, so it also floats over the `#projects` section (cream-sakura background, no video). There it must still read at ≥ 3:1. The executor checks it at the Projects section. If the 70% scrim measures below 3:1 there, raise it to `color-mix(in oklab, var(--plum) 92%, transparent)`, the value already used by the mobile menu. Do not add a new colour.
- Focus ring: 2px `var(--sakura)` outline with a 2px offset. Against the dark scrim that is about 6:1 (≥ 3:1 required by 2.4.13 / 1.4.11).

## Component Contracts

### 1. Hero video (`Hero` in `src/routes/index.tsx`)

Markup changes. The layout, gradient, `h1`, subtitle and CTA are unchanged.

| Attribute | Contract |
|-----------|----------|
| `src` | The hero MP4 path from `media.generated.ts` (H.264 High 8-bit `yuv420p`, bt709 SDR, 30 fps, no audio track, `+faststart`, **≤ 4 MB**) |
| `poster` | The hero poster WebP from the manifest: first frame of the **converted SDR output**, native width (1080px, the master is 1080×574), **≤ 110 KB** (measured: WebP q60 ≈ 104 KB — decision added after research). It must match frame 0, so autoplay starts without a visible jump in colour or framing. |
| `preload` | `"metadata"` (was `"auto"`) |
| `muted`, `loop`, `playsInline` | present |
| `autoPlay` | **removed**. Playback starts from JS after hydration so that `prefers-reduced-motion` is honoured before any frame moves (see the state machine). |
| `aria-hidden` | `"true"`. The video is decorative and the toggle is its accessible control. |
| Fallback text | Keep the existing `Votre navigateur ne supporte pas la vidéo HTML5.` unchanged. |
| Poster preload | Add a `<link rel="preload" as="image" type="image/webp" href={poster} fetchpriority="high">` in the index route `head()`. **This is the only preloaded resource on the site** (SIZE-08). The poster is the LCP element. |
| Old poster | `/assets/hero.png` (4.37 MB) is no longer referenced. |

**Playback state machine.** One `useState<"playing" | "paused">`, initial value `"paused"`. SSR renders the paused UI, so there is no hydration mismatch.

| Trigger | Result | Toggle icon | `aria-pressed` |
|---------|--------|-------------|----------------|
| Mount, `matchMedia("(prefers-reduced-motion: reduce)")` **false** | call `video.play()`. On resolve → `playing` | pause glyph | `false` |
| `play()` rejected (iOS Low Power Mode, data saver, policy) | stay `paused`, poster stays visible, no error UI | play glyph | `true` |
| Mount, reduced motion **true** | no `play()` call. Poster stays. | play glyph | `true` |
| User activates toggle while `playing` | `video.pause()` → `paused`, remember `userPaused = true` | play glyph | `true` |
| User activates toggle while `paused` (also under reduced motion: an explicit request is allowed) | `video.play()` → `playing`, `userPaused = false` | pause glyph | `false` |
| `document.visibilitychange` → hidden | `video.pause()` silently (do not set `userPaused`) | unchanged | unchanged |
| `visibilitychange` → visible | resume only if `!userPaused` and reduced motion is false | unchanged | unchanged |
| Native `play` / `pause` events on the video | sync state from them, the single source of truth (covers Safari-injected controls) | derived | derived |
| Video `error` event | hide the toggle (`hidden`) and leave the poster. There is no error message: the page still reads correctly. | none | none |

**Toggle button (new, inline in `Hero`, no new file required).**

| Property | Contract |
|----------|----------|
| Element | `<button type="button">`, the only new interactive element of the phase |
| Position | `fixed`, `z-30` (under the nav's `z-40`), `bottom-4 right-4` (16px) below 640px, `sm:bottom-6 sm:right-6` (24px). Add `env(safe-area-inset-bottom)` / `env(safe-area-inset-right)` to the inset on iPhone. The button is fixed because the hero video is also the backdrop of About and Contact, so its pause control must remain reachable (WCAG 2.2.2). |
| Size | `h-11 w-11` (44 × 44px) hit area, icon `h-5 w-5` (20px) centred |
| Shape and surface | `rounded-[2px]` (matches `quest-btn`/`hud-tag`), 1px border `color-mix(in oklab, var(--gold) 70%, transparent)`, background `color-mix(in oklab, var(--plum) 70%, transparent)`, `backdrop-blur-[6px]`, icon `text-[var(--cream)]` |
| Hover | background `color-mix(in oklab, var(--sakura) 35%, var(--plum))`, the same as `quest-btn:hover`. **No** translate and no glow (a small control must not jump). |
| Focus | `focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-[var(--sakura)]`. The focus ring must never be removed. |
| Transition | `transition-colors duration-300`. Under `motion-reduce:` use `transition-none`. |
| Icons | Play: `<path d="M8 5v14l11-7z"/>`, the glyph already used on the CV video. Pause: `<path d="M7 5h3.5v14H7zM13.5 5H17v14h-3.5z"/>`. Both `aria-hidden="true"`. |
| Accessible name | **Constant** visually hidden text `Mettre en pause la vidéo` (`<span className="sr-only">`). State is conveyed by `aria-pressed` (true = paused), following the WAI-ARIA APG toggle-button rule: the label does not change when `aria-pressed` is used. Do not also swap the label to « Lire la vidéo ». That would double-announce. |
| Keyboard | Native button: Tab reaches it after the nav links in DOM order (place it right after the `<video>` wrapper inside `Hero`), Space/Enter toggle. |
| Must not overlap | the "↓ Scroll" cue (bottom-centre) or the mobile menu (top). Transient overlap with scrolling content is accepted, because the content moves under a 44px corner control. |

### 2. `<Picture>` (new, `src/components/Picture.tsx`, the only image component)

| Prop | Type | Contract |
|------|------|----------|
| `id` | `MediaId` (key union exported from `src/data/media.generated.ts`) | Required. An unknown id is a **type error**, not a runtime empty state. |
| `alt` | `string` | Required. `""` only for purely decorative images. |
| `sizes` | `string` | Required. Use the values in the table below. |
| `className` | `string?` | Applied to the `<img>` by template-literal concatenation (`cn()` was removed in phase 1) |

Rendered output:
```
<picture className="contents">
  <source type="image/avif" srcSet="…-640.avif 640w, …-1200.avif 1200w, …-2400.avif 2400w" sizes={sizes} />
  {preset === "photo" && <source type="image/webp" srcSet="… 640w, … 1200w, … 2400w" sizes={sizes} />}
  <img src={fallback} width={w} height={h} alt={alt} loading="lazy" decoding="async" className={`h-auto ${className ?? ""}`} />
</picture>
```
- Widths are never upscaled. A width larger than the source is omitted by the manifest. Grid tiles (card thumbnails) get at most 1200.
- Presets: `photo` uses AVIF 4:2:0, WebP and a JPEG fallback. `graphic` (default) uses AVIF 4:4:4 and a quantised PNG fallback with **no WebP source**, which avoids lossy chroma bleed on type (Pitfall 13).
- `width` and `height` always come from the manifest, so there is no layout shift. Existing `object-cover` / `aspect-[4/5]` classes keep working because `className` lands on `<img>`.
- **No `priority` / eager prop in this phase.** Nothing rendered by `<Picture>` is preloaded. Only the hero poster is (§1).

`sizes` values (layout containers are unchanged):

| Context | Container | `sizes` |
|---------|-----------|---------|
| Home project card thumbnail (`ProjectCard`) | `max-w-7xl`, grid 1 / `sm:2` / `lg:3`, `gap-8` | `(min-width: 1280px) 395px, (min-width: 1024px) 31vw, (min-width: 640px) 46vw, calc(100vw - 48px)` |
| About portrait | `.portrait-image` max 350px / 280px | `(min-width: 640px) 350px, 280px` |
| Project page, 2-column gallery or block grid | `max-w-4xl` (896px), `sm:grid-cols-2`, `gap-4` | `(min-width: 944px) 440px, (min-width: 640px) calc(50vw - 32px), calc(100vw - 48px)` |
| Project page, full-width single image | `max-w-4xl` | `(min-width: 944px) 896px, calc(100vw - 48px)` |
| Project page, capped image (`max-w-xs` logo, `max-w-md` palette) | fixed cap | `320px` / `448px` |

### 3. Project galleries (`src/routes/projects/$projectId.tsx`, `src/data/projects.ts`)

- **Grid rhythm unchanged.** The generic `project.media` gallery keeps `mt-12 grid gap-4`, with `sm:grid-cols-2` when there is more than one item: 1 column below 640px and 2 columns from 640px. The home project grid keeps 1 / 2 / 3 columns (`sm`, `lg`). *Deviation from the orchestrator note "3 columns ≥ 1024":* project-page galleries have always been 2 columns inside `max-w-4xl`. A third column would be a new layout and would shrink brand-guide planches to about 288px, where their typography becomes unreadable. The 3-column rhythm stays on the home grid only.
- Tiles keep `w-full rounded-md object-cover shadow`, with height from the intrinsic ratio (`h-auto`). There are no captions, no lightbox and no hover effect in this phase.
- `project.media` becomes `MediaId[]`, and `thumbnail` becomes a `MediaId`. Every `<img>` inside the `business-card-mockup`, `clip`, `sae-2` and `sae-1` branches becomes `<Picture>` with the **same classes, same order and same headings** (PROJ-07). Only the source changes, from `/assets/…` to a manifest id. Every branch stays in place.
- **Tafsut gallery (« Identité d'un festival », `festival-identite`):** about 10 planches rendered through the generic `project.media` gallery below the "Le projet" card. There is no custom branch. The order is fixed by `media-src/manifest.json`: logo → palette → typographies → affiche → billets → goodies → signalétique (extra pages are inserted next to their theme). Every planche uses the `graphic` preset.
- `inProgress: true` is removed from `festival-identite`, so the yellow "En cours de dev" sticker disappears from its home card and the card becomes clickable. Other projects' `inProgress` flags and the sticker component are untouched.
- `charte_graphique.pdf` is no longer linked or served. There is no download link to the PDF in this phase.

## Motion & Accessibility Contract

- WCAG 2.2 AA floor. 2.2.2 (Pause, Stop, Hide) is met by the fixed toggle. 2.5.8 target size is met by 44 × 44px. 2.4.7 / 2.4.13 focus visibility is met by the sakura outline. 1.4.11 non-text contrast is at least 3:1 wherever the toggle sits (≈ 8:1 over the hero).
- `prefers-reduced-motion: reduce` means no autoplay. The poster stays and the toggle is shown in the paused state. The toggle's colour transition is disabled under `motion-reduce`. Guarding `Reveal`, hover scales and the portrait is **not** in scope (phase 3 ships the global motion guard together with the new cinematic effects, Pitfall 12).
- The hero video carries no audio track, so there is no sound control.
