## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Mesure SSIM décalée d'une image**
- **Found during:** Task 1 (premier `npm run media` : SSIM 0,8061 au lieu des 0,915 de la recherche, avec un WARN)
- **Issue:** `setpts=N/30/TB` sur la référence MKV (timebase 1/1000) arrondit les pas de 33,33 ms ; le filtre ssim produit 507 images pour 506 et apparie avec une image de décalage à partir de n = 2.
- **Fix:** `settb=1/<fps>,setpts=N` sur les deux entrées dans `ssim()` de `scripts/media/util.mjs` → 0,9159 (cohérent avec la recherche). Commentaire explicatif dans le code.
- **Files modified:** scripts/media/util.mjs
- **Commit:** 09c67ca

**2. [Rule 1 - Bug] Poster du hero en 404 sous le Worker**
- **Found during:** Task 2 (vérification wrangler dev)
- **Issue:** `run_worker_first: ["/media/video/*", …]` (plan 01) envoie aussi `hero-poster.webp` au Worker ; `src/server.ts` ne traitait que les `.mp4` et passait le reste au handler SSR → 404. Le preload et le poster auraient été cassés en production.
- **Fix:** tout chemin non-MP4 sous `/media/video/` ou `/animate/videos/` est renvoyé à `env.ASSETS.fetch(request)` → 200 `image/webp` ; les chemins inexistants restent en 404.
- **Files modified:** src/server.ts (hors liste `files_modified` du plan, correctif bloquant)
- **Commit:** e9d778f
