## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet → Worker `src/server.ts` | URL, méthode et en-têtes (dont `Range`) non fiables, pour les chemins `/media/video/*` et `/animate/videos/*` (run_worker_first) |
| Worker → Cache API (`caches.default`) | cache partagé par datacenter : une entrée empoisonnée toucherait tous les visiteurs |
| Worker → `env.ASSETS` | lecture seule des fichiers publics déployés |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
